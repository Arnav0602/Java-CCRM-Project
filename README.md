# Java-CCRM-Project

# Introduction

The Campus Course & Records Manager (CCRM) is a simple Java console-based application that manages students, courses, and enrollments.
It allows users to add students, add courses, and enroll students into courses using a clean, menu-driven interface.

This project is created using Java programming, problem-solving, and Object-Oriented Programming concepts.


# Project Structure
CCRM_Project/

├── CCRM.java

└── README.md


# Requirements
1) Java JDK 8 or above installed on your system

2) A terminal or command prompt

# Problem Statement
In many educational environments, student and course information is managed manually. This leads to problems such as:

1) Difficulty maintaining updated records

2) Errors when handling enrollments

3) No centralized way to connect students to their courses

There is a need for a simple automated system that can:

1) Store & retrieve student data

2) Store & retrieve course data

3) Easily enroll students in courses

4) Display complete records clearly

This project provides a basic digital solution to manage these tasks efficiently.

# Objectives
1) To build a clean, menu-driven Java application

2) To apply Object-Oriented Programming concepts

3) To use ArrayLists for dynamic in-memory data storage

4) To simplify enrollment management

5) To prevent input errors using basic validation and exception handling


# Features
1) Add Student (ID, Name, Email)

2) Add Course (Code, Title, Credits)

3) Enroll Student in Course

4) View All Students

5) View All Courses

6) View All Enrollments

7) Safe Input Handling (prevents program crashes)

8) Exit Program

# Working of the Program
1) The program displays a menu to the user.

2) The user selects an option.

3) Based on the choice:

 a) A student is added
 
 b) A course is added
 
 c) A student is enrolled in a course
 
 d) Student/course/enrollment lists are displayed
 
4) Input validation ensures safe interaction

5) The program continues running until the user chooses Exit

# Concepts Used
1) Classes & Objects

2) Encapsulation

3) ArrayList for storing dynamic data

4) Loops (for, while)

5) Conditional statements (if-else, switch)

6) Exception handling (try-catch, input validation)

7) Simple search operations using loops


# System Design
This project contains all logic inside one Java file but structured into separate classes:

1) CCRM.java (Main File)

2) Contains the Main Menu

3) Contains Student, Course, and Enrollment classes

4) Contains all program logic

5) Uses ArrayLists to store data


# How to run
1) Clone the Repository

Open your terminal or command prompt and run:

git clone https://github.com/your-username/your-repository-name.git

This will download the entire project folder to your computer.

2) Navigate Into the Project Folder

Move into the cloned directory:

cd your-repository-name

3) Compile the Program

Use javac to compile the Java file:

javac StudentCourseManager.java

If your file has a different name, use that instead.

4) Run the Program

Start the application using:

java StudentCourseManager

The program will launch in your terminal, and you can interact with it using the menu options.
